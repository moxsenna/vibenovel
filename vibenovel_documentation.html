VibeNovel v2: Master Architecture

VibeNovel v2 is a state-of-the-art, AI-powered progressive web application designed to orchestrate the entire novel-writing process. Built with a 100% Client-Side Architecture, the platform integrates deeply with Supabase and multiple AI providers directly from the browser, ensuring zero intermediary server latency and seamless native-wrapper export capabilities (Capacitor ready).

Core Philosophy

Everything runs in the browser. Database syncing is handled via Supabase Auth & PostgreSQL. AI requests stream directly to Gemini and OpenRouter using a Bring Your Own Key (BYOK) system guarded strictly within local storage. No custom backend server.

Frontend Architecture

Vite 6.x React 19.x TypeScript 5.x Zustand 5.x Tailwind CSS 4.x Framer Motion

The application is a Single Page Application (SPA) driven by React Router. The interface centers around a dynamic Mode-Based Workspace that conditionally swaps views (Brainstorm, Outline, Write, Review, Visualize) while preserving state and scroll position.

Modular State (Zustand)

The monolithic store was refactored into distinct parts: projects, chapters, lorebook, and outlines. This ensures isolated re-renders, clean TypeScript boundaries, and safe persistence to `localStorage`.

Verbatim Module Syntax

Strict TypeScript compilation rules enforce import type for all interfaces and aliases, stripping type definitions from the final JS bundle for maximum performance.

Lazy-Loaded Modules

Heavy libraries like Recharts, D3.js (Constellation Map), Mammoth (.docx), and PDF.js are chunked and lazy-loaded only when requested, keeping the initial load under 200KB gzipped.

Theme & Styling System

VibeNovel v2 utilizes a meticulously crafted Dual-Theme System designed for both casual authors and professional writers.

  • Malam Kreatif (Dark Mode): A warm, magical night desk vibe with deep plum/burgundy surfaces (#1A1118) and rose gold accents.
  • Jurnal Cantik (Light Mode): A premium, physical paper journal aesthetic utilizing soft ivory cream (#FDF8F5) and delicate taupe text.
Zero-Flicker Engineering

Themes are synced directly to document.documentElement using CSS variables (`--color-bg-primary`, `--color-surface-hover`, etc.). An inline script block in index.html synchronously parses `localStorage` before React mounts, ensuring absolutely no "flash of white light" when opening the app in Dark Mode.

Story Compass & Brainstorming

The Story Compass acts as the narrative foundation, ensuring all primary structural components are locked in prior to writing.

5 Core Story Pillars

Tracks and structures the Premise, Protagonist, Antagonist, Target Ending, and active Mystery Layers (with localized mystery breadcrumbs).

Segmented Progress & Gap Detector

A dynamic visual progress indicator checks for missing pillars and prompts the user with pulsating indicators to ensure cohesive brainstorming.

Co-Author Chat & Anti-Melantur

An interactive, AI-driven brainstorming environment. The Anti-Melantur Guard prevents off-topic digressions: after 3 consecutive off-topic loops, the AI forcefully drafts a structural proposal to refocus the author.

Season Architect & Outline Engine

The Season Architect generates structured chapter blueprints that strictly follow melodrama retention rhythms.

Story Compass Safeguard

Prevents arbitrary outline generation unless the core Story Compass pillars are complete. Outlines are woven with consistent cliffhangers and dopamine cycles.

Sequential Await Generation

To avoid AI amnesia, chapter outlines are generated chronologically. The contextual output of Chapter N is dynamically fed as preceding memory for Chapter N+1.

Deep Outline & Pacing Validator

Leverages Gemini's non-streaming reasoning mode to place mystery clues logically across sub-arcs. A warning-only pacing validator warns the user of flat emotional zones or monotone cliffhangers.

Prose Editor & Strict Mode

A premium distraction-free environment that balances structured guidance with creative freedom.

Beat-by-Beat Strict Mode

Narrows naskah generation down to scene-level events. Writing progresses in manageable chunks mapped directly to localized scene beats and outlines.

Free Write Mode

Toggles off all structured beat boundaries, providing a wide-open plain text canvas. When toggled off, a Sync Watcher identifies unindexed chapters and initiates sequential background backfilling.

Debounced Auto-Save

Keeps drafts perfectly preserved. Slices the prose buffers and executes local + Supabase syncing after 2 seconds of inactivity to guarantee zero data loss.

AI Architecture & Provider Pool

The application employs a sophisticated abstraction layer capable of routing specific tasks to the most cost-effective or high-performance LLM available.

Gemini Multi-Key Pool

A round-robin balancing system for free Gemini API keys. Includes strict 60-second cooldown rate-limiting guardrails and BYOK Guard, which completely masks API keys from console logs to prevent accidental leakage.

OpenRouter Adapter

When the highest prose quality is demanded, the AI Router dynamically swaps to Claude 3.5 Sonnet or Deepseek v4 via OpenRouter for prose generation, preserving Gemini for background administrative tasks.

Server-Sent Events (SSE)

All generative text features leverage streaming. Responses are parsed chunk-by-chunk in real-time, feeding React state progressively without blocking the main thread.

The 4-Layer Memory System

To combat AI amnesia and manage token budgets effectively (targeting ~8000 tokens per beat), context injection is aggressively pruned across four distinct layers:

  1. Layer 1: Static Lorebook - Always injects the Narrative Constitution, Melodrama Protocol, Target Ending, and active Mystery Layers. Characters/Items are only injected if their names literally match the scene's outline (Keyword Pruning).
  2. Layer 2: Dynamic State - Extracts 10 crucial fields for characters involved in the scene (Location, Emotional State, Inventory, Secrets, Goals) calculated dynamically from the previous chapter's end-state.
  3. Layer 3: RAG Long-Term Memory - Utilizes Supabase `pgvector` and Gemini `text-embedding-004`. Semantically fetches the 3 most relevant previous chapter summaries to maintain distant context.
  4. Layer 4: Sliding Window - Grabs the literal last 500 words of the previous chapter to seamlessly carry over prose style, tone, and mid-dialogue cuts. Also includes a "read-only fence" of the next 2 chapter outlines to prevent plot rushing.

3-Column Desktop Workspace

Categorizes writing checks into CRITICAL, WARNING, and INFO tiers across four axes: Plot Holes, Emotional Breather intervals, Chekhov's Gun tracking, and Filler detection.

PWA & Offline Resilience

VibeNovel v2 is a fully installable Progressive Web App powered by vite-plugin-pwa with Workbox caching strategies.

  • Offline Draft Fallback: If the user loses connection while typing in the BeatEditor, the useOfflineDraft hook automatically intercepts the debounced save and commits the payload to `localStorage`.
  • Auto-Sync Recovery: Upon detecting network reconnection, background queues silently replay all cached drafts to the Supabase PostgreSQL database.
  • Smart Strategy: Local assets and fonts use `CacheFirst`, Supabase queries use `NetworkFirst`, and AI calls are strictly `NetworkOnly`.

Pro Writer Features

4-Step Import Wizard

Reads .docx, .pdf, and .txt. Utilizes a dual-tier AI analysis: a fast Quick Scan (compressed sample) followed by Deep Analysis on critical chapters to establish Voice DNA and prepopulate the Story Compass.

Director's Cut Modal

Offers 3 sequential streaming rewrites (Tighter, Emotional, Dramatic). When the user accepts one, the system sends an AbortSignal to immediately kill the remaining pending streams, saving API costs.

Selection Magic Edit

A Medium/Notion-style floating toolbar that appears upon text selection. Integrates directly with Gemini 2.0 Flash Lite for ultra-fast, surgically precise inline text replacement.

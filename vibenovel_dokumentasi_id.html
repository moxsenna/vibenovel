VibeNovel v2: Master Arsitektur

VibeNovel v2 adalah aplikasi web progresif (PWA) canggih bertenaga AI yang dirancang untuk mempermudah seluruh proses penulisan novel dari hulu ke hilir. Dibangun dengan Arsitektur 100% Client-Side, platform ini terintegrasi langsung dengan Supabase dan berbagai penyedia AI langsung dari peramban (browser) pengguna tanpa perantara server backend custom, menjadikannya sangat cepat, aman, dan siap dibungkus oleh Capacitor CLI untuk platform mobile.

Filosofi Inti BYOK (Bring Your Own Key)

Seluruh operasi data berjalan langsung di browser pengguna. Kunci API (Gemini dan OpenRouter) disimpan secara lokal menggunakan Zustand persist middleware dan tidak pernah dikirim ke database eksternal manapun.

Arsitektur Frontend

Vite 6.x React 19.x TypeScript 5.x Zustand 5.x Tailwind CSS 4.x Framer Motion

Aplikasi ini mengadopsi Single Page Application (SPA) berbasis React Router 7. Antarmuka pengguna berpusat pada sebuah Mode-Based SPA Canvas dinamis yang menukar mode kerja secara instan (Brainstorm, Outline, Write, Review, Visualize) dengan transisi animasi halus dari Framer Motion.

Modular State (Zustand Parts)

Monolit store utama dipecah secara rapi menjadi modul independen: projects, chapters, lorebook, dan outlines guna mempercepat re-render dan mempermudah debugging.

Verbatim Module Syntax

Menerapkan aturan impor tipe-only (import type) TypeScript yang sangat ketat untuk memastikan tidak ada overhead tipe data dalam hasil kompilasi produksi.

Lazy-Loaded Heavyweight

Komponen analitis berat seperti D3.js (Constellation Map), Recharts, Mammoth (.docx), dan PDF.js dimuat secara asinkron hanya saat dibutuhkan agar aplikasi pertama kali dimuat di bawah 1 detik.

Sistem Tema & Visual Premium

VibeNovel v2 menghadirkan Dual-Theme System berkualitas premium yang didesain ramah mata untuk sesi penulisan maraton:

  • Malam Kreatif (Dark Mode): Estetika meja kerja malam hari yang hangat & magis menggunakan warna burgundy/plum gelap (#1A1118) dan pendar rose gold.
  • Jurnal Cantik (Light Mode): Estetika jurnal kertas planner premium dengan latar cream lembut (#FDF8F5) dan warna teks cokelat tua hangat.
Anti-Flicker (Bebas Kedipan Layar Putih)

Menggunakan blok skrip mini sinkron di index.html sebelum tag body yang membaca localStorage tema secara instan untuk mencegah flicker warna putih saat halaman dimuat ulang di Dark Mode.

Story Compass & Brainstorming

Story Compass bertindak sebagai kompas narasi cerita untuk menyusun struktur pondasi utama sebelum outline dibuat.

5 Pilar Utama

Melacak kelengkapan Premis, Protagonis (dengan Voice DNA), Antagonis, Target Ending, dan Lapisan Misteri.

Pendeteksi Celah (Gap Detector)

Visual segmented progress bar yang secara aktif mendeteksi pilar mana yang belum lengkap dan memberi tahu penulis melalui petunjuk berdenyut.

Anti-Melantur Guard

Saat berdiskusi dengan Co-Author AI, sistem memantau percakapan melantur di luar cerita. Jika terdeteksi 3x berturut-turut, AI akan dipaksa menyajikan kartu proposal struktur agar diskusi kembali terarah.

Season Architect & Outline Engine

Season Architect mengotomatisasi penyusunan rancangan outline per bab dengan berpedoman pada ritme melodrama penahan retensi pembaca.

Sequential Await Loop

Outline bab digenerasi berurutan secara kronologis. Rangkuman detail bab N dijadikan input memori kontekstual bab N+1 untuk menghindari lompatan logika plot yang terburu-buru.

KBM Pacing Validator

Sistem pengecekan ritme naskah otomatis. Memberikan peringatan apabila naskah terlalu monoton, kurang klimaks, atau memiliki penempatan misteri yang kurang merata.

Deep Outline reasoning

Mengaktifkan mode penalaran terarah (thinking budget) pada model AI saat merancang outline guna menyisipkan petunjuk misteri secara rapi di bab-bab tertentu.

Prose Editor & Strict Mode

Kanvas menulis premium yang memberikan fleksibilitas tinggi bagi penulis naskah.

Strict Beat-by-Beat

Menulis naskah dengan tuntunan ketat dari poin adegan outline. Menjaga tulisan agar terstruktur rapi dan tidak melenceng dari outline awal bab.

Free Write Canvas

Mode naskah bebas tanpa panduan beat naskah. Memberi kebebasan berekspresi penuh bagi penulis dengan backup sinkronisasi otomatis pasca-penulisan selesai.

Offline Autosaver

Mengamankan tulisan secara otomatis ke localStorage saat offline, dan mengunggahnya secara sunyi ke Supabase setelah koneksi terdeteksi terhubung kembali.

Arsitektur AI & Pool Kunci API

Sistem backend-less AI Router VibeNovel v2 dirancang untuk memaksimalkan ketersediaan API gratisan serta kemudahan kustomisasi model premium:

Gemini Multi-Key Pool

Mendukung rotasi seimbang beberapa kunci API Gemini gratisan milik pengguna (round-robin) lengkap dengan masa cooldown pemulihan mandiri jika terkena batasan rate limit.

OpenRouter Premium Adapter

Menghubungkan model terkemuka dunia seperti Claude 3.5 Sonnet atau Deepseek Chat via OpenRouter dengan konfigurasi satu pintu yang fleksibel.

Stream Delivery (SSE)

Pengiriman token teks bergaya mesin tik secara real-time yang memangkas waktu tunggu respon model AI hingga di bawah 300ms.

Sistem Memori 4-Layer Context

Untuk menghemat token input dan menjaga pemahaman alur cerita yang panjang, penyusunan instruksi AI disaring ketat melintasi empat lapisan berikut:

  1. Layer 1: Static Lorebook - Aturan cerita, konstitusi naskah, dan target ending. Tokoh dan barang hanya disertakan jika terdeteksi kecocokan literal di outline bab berjalan (Pruning).
  2. Layer 2: Dynamic State - Memuat status 10-field tokoh-tokoh yang terlibat langsung dalam adegan (Lokasi, Kondisi Fisik, Relasi, Rahasia) guna menghindari inkonsistensi aksi karakter.
  3. Layer 3: RAG Long-Term Memory - Pencarian semantik menggunakan vektor `pgvector` Supabase untuk memanggil kembali ingatan bab-bab lampau yang paling relevan dengan naskah baru.
  4. Layer 4: Sliding Window - Menyertakan 500 kata literal terakhir dari bab sebelumnya untuk mempertahankan kelancaran gaya bahasa naskah.

Panel Review & QA Radar

Panel komprehensif pasca-menulis untuk menjaga kepatuhan logika penulisan, melacak resolusi misteri, serta memindai naskah.

Desktop 3-Column Layout

Antarmuka pembaca naskah, log radar plot hole, dan panel sub-plot sampingan bersanding serasi pada layar desktop. Berubah menjadi tab geser adaptif pada mobile.

Severity Filtering Chips

Memfilter temuan radar plot dari kategori kritis (*Critical*), peringatan emosional naskah datar (*Warning*), hingga saran penulisan (*Info*).

LoreDiff & Thread Tracker

Menampilkan tokoh atau benda baru yang menyelinap ke naskah naskah. Melacak masa hidup utas plot (*plot thread*) dengan indikator kedip merah penanda utas kritis.

Visualisasi Data & Arc Emosi

Mengubah naskah teks mentah menjadi bagan visual analitik premium yang kaya informasi demi membantu penulis menganalisis pacu tulisan mereka.

D3.js Constellation Map

Grafik force-directed interaktif yang menggambarkan hubungan relasi antar tokoh, item, dan aturan dunia berdasarkan tingkat keterlibatan mereka per bab.

PWA & Ketahanan Offline

VibeNovel v2 dikonfigurasi menggunakan plugin vite-plugin-pwa untuk pengalaman luring (offline) yang tangguh layaknya aplikasi native mobile.

  • Precached Static Assets: Menyimpan aset inti visual, berkas kode JS, serta font Google Fonts untuk pemuatan luring.
  • Caching Supabase API: Menerapkan taktik `NetworkFirst` pada panggilan data profil guna mengantisipasi hilangnya koneksi secara tiba-tiba.
  • PwaUpdatePrompt: Toast notifikasi dinamis saat naskah siap diakses offline atau saat ada pembaruan kode aplikasi terbaru.

Fitur Pro Writer

Fitur premium tingkat lanjut yang dirancang khusus untuk mempermudah pekerjaan penulis profesional:

Import Wizard (4 Langkah)

Membaca berkas manuskrip berformat .docx, .pdf, dan .txt. Melakukan ekstraksi tokoh secara otomatis serta merekonstruksi Story Compass naskah lama dengan cepat.

Director's Cut Modal

Menawarkan 3 variasi penulisan ulang naskah (Tighter, Emotional, Dramatic). Memiliki efisiensi API tinggi di mana memilih salah satu variasi akan otomatis membatalkan sisa stream variasi lainnya (AbortSignal).

Selection Magic Edit

Toolbar mini melayang ala Notion/Medium yang muncul saat seleksi teks naskah. Terintegrasi dengan model super cepat Gemini Flash Lite untuk merevisi teks secara presisi di tempat.
